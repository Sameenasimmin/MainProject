# MainProject

Abstract:
The rapid evolution of recruitment technologies has created a demand for automated solutions that go beyond traditional resume screening. In this context, the proposed project introduces an NLP and Machine Learning-based Video Resume Screening System that aims to revolutionize how candidates are evaluated in modern hiring environments. By leveraging state-of-the-art artificial intelligence techniques, the system automates the assessment of video resumes, analyzing both the verbal content and the delivery to extract key candidate insights. It ensures a more efficient, objective, and data-driven hiring process by minimizing manual intervention, reducing unconscious bias, and accelerating candidate shortlisting.
The system follows a multi-stage pipeline beginning with speech-to-text conversion using models like OpenAI Whisper and Google Speech-to-Text API, which transcribe spoken content into accurate text. This is followed by text summarization, named entity recognition (NER), and grammar and fluency analysis using advanced NLP frameworks such as BERT, T5, spaCy, and TextBlob. Additionally, sentiment and emotion analysis models like VADER and RoBERTa are employed to detect confidence, enthusiasm, and other emotional markers in a candidate's speech. These components work in unison to provide a comprehensive evaluation of a candidate’s communication skills, qualifications, and presentation effectiveness. The extracted insights are compiled into a structured report, simplifying the recruiter’s task of comparing applicants and making informed decisions.
Tested on a diverse dataset of video resumes from multiple job categories, the system demonstrated a classification accuracy of 82% on test data. It successfully extracted relevant skills, experience levels, and job-specific details with high precision. Furthermore, the system’s design supports scalability and modular integration into existing Applicant Tracking Systems (ATS). Future enhancements such as gesture and facial expression recognition, real-time candidate feedback, blockchain-based verification, and multilingual support are expected to further increase the tool's capabilities. This project represents a significant advancement in AI-driven recruitment technology and sets the foundation for smarter, more inclusive, and highly efficient hiring systems.
 
Key Words: Machine Learning, Natural Language Processing, Speech-to-Text Conversion, Named Entity Recognition, Bias Reduction, Resume Intelligence, Emotion Detection.
